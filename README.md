# Gestor de Tareas CLI

A command-line task manager built in Python as part of my Blue Team portfolio roadmap.

## Features
- View all tasks
- Add new tasks
- Delete tasks
- Data persistence using .txt file

## How to run

    python main.py

## What I learned
- Functions and parameters
- File handling (read/write)
- While loops and conditionals
- Lists and f-strings
